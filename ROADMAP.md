# Cairo Security Learning Roadmap

Welcome to the Cairo Security Learning Roadmap! This comprehensive guide provides curated resources to help you master Cairo security, from foundational concepts to advanced vulnerability analysis and real-world contest experience.

Whether you're just starting with Cairo or looking to deepen your security expertise, this roadmap offers a structured path through essential documentation, security courses, common vulnerability patterns, and practical challenges from past security contests.

## Documentation and Language Foundations

Master the fundamentals of Cairo programming language and its ecosystem:

- [Cairo Book](https://www.starknet.io/cairo-book/) - The comprehensive guide to Cairo programming language
- [Cairo Tutorials](https://www.cairo-lang.org/tutorials/) - Step-by-step tutorials for learning Cairo

## Security Courses and Common Vulnerabilities

Dive deep into Cairo security with specialized courses, CTF challenges, and vulnerability databases:

- [Free Cairo Security Course](https://academy.extropy.io/pages/courses/cairo-security-landing.html) - Comprehensive security course covering Cairo-specific vulnerabilities
- [Cairo Security by Spearbit](https://www.youtube.com/watch?v=9CIhHNrliW4) - Expert insights on Cairo security from Spearbit
- [Cairo CTF](https://nodeguardians.io/campaigns/bad-accounts/quests/stealing-souls?s=devhub-campaigns) - Hands-on CTF challenges to practice security skills
- [Starknet Basecamp](https://www.youtube.com/playlist?list=PLMXIoXErTTYXlL2OmA0N7rLZGZBa48YN6) - Video series covering Starknet fundamentals and security
- [Common Vulnerabilities](https://fuzzinglabs.com/top-4-vulnerability-cairo-starknet-smart-contract) - Top 4 vulnerabilities in Cairo/Starknet smart contracts
- [More Common Vulnerabilities](https://github.com/crytic/building-secure-contracts/tree/master/not-so-smart-contracts/cairo) - Collection of vulnerable Cairo contract patterns
- [Verified algebraic representation of Cairo execution](https://arxiv.org/abs/2109.14534) - Formal proof paper on Cairo's execution model
